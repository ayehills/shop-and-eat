Flyer Studio

Purple Graduation Flyer Maker

A Photoshop-style pipeline: AI background removal, edge-refined alpha matting, and a high-resolution HTML/Canvas compositor that rebuilds a premium flyer from a template.

Download PNG (2160×2160) Download JPG

How it was made

1 · Cut out
U²-Net segmentation + closed-form alpha matting isolates the graduate with clean hair/beard edges — the photo pixels are never altered.
2 · Theme
The red template's composition is re-skinned into a purple & gold palette with 3D metallic type.
3 · Compose
Text, flying caps, diplomas, sparkles and the subject are layered in HTML and rendered at 2× for print-grade crispness.

Rebuild it yourself

  1. pip install pillow numpy onnxruntime pymatting
  2. python3 flyer/cutout.py — removes the background from the source photo
  3. python3 flyer/generate.py — builds flyer/build/flyer.html
  4. node flyer/render.js — screenshots it to a 2160×2160 PNG
